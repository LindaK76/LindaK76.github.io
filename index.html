En kort introduktion

Så fungerar Claude Code

Claude Code är en AI-assistent som inte bara svarar på frågor – den kan läsa dina filer, köra kommandon och göra ändringar åt dig, steg för steg.

Vad är det?

En vanlig chatt-AI ger dig text som du själv får kopiera och använda. Claude Code jobbar istället direkt i din dator: i en mapp du väljer, med de verktyg som finns där. Du beskriver vad du vill ha gjort med vanliga ord, och Claude tar fram en plan och utför den.

Hur ett uppdrag går till

  1. Du beskriver måletTill exempel: ”Gör en enkel hemsida om hur Claude Code fungerar.”
  2. Claude undersökerLäser filerna i mappen och tittar på vilka program som finns, för att förstå utgångsläget.
  3. Claude agerarSkriver och ändrar filer, kör kommandon i terminalen och söker information vid behov.
  4. Claude kontrollerarTestar resultatet, ser om något gick fel och rättar till det.
  5. Du granskarDu får en sammanfattning av vad som gjorts och bestämmer nästa steg.

Du har kontrollen

Claude frågar om lov innan den gör saker som är svåra att ångra – till exempel att radera filer, publicera något eller logga in någonstans. Inloggningar och lösenord sköter du själv.

Var finns Claude Code?

Terminalen

Starta med kommandot claude i valfri mapp.

Skrivbordsappen

Claude-appen för Mac och Windows har en egen Code-flik.

Webben

Via claude.ai/code, direkt i webbläsaren.

Kodeditorer

Tillägg för bland annat VS Code och JetBrains.

Tips för att komma igång

Var tydlig

Säg vad du vill uppnå och för vem – inte bara vilken knapp du vill ha.

Ta små steg

Börja enkelt och bygg vidare. Det är lättare att följa med.

Fråga ”varför?”

Be Claude förklara vad den gör. Du lär dig samtidigt.
